# Teacher guide

1. **Become a teacher** — `/become-a-teacher` adds teacher mode to your existing account (same login). Switch between student and teacher with the role switcher.
2. **Profile** — *Teach → Public profile*: headline, bio, teaching approach, subjects, levels, languages, hourly rate and currency, online / in-person, timezone, intro video link. The completeness indicator on *Teach → Overview* shows what is missing.
3. **Location** — choose *private* (no map pin), *approximate* (default, ~2 km area) or *public*. Pick your city from the list, or search an address if a geocoding provider is configured. Your exact address is never shown publicly.
4. **Offerings** — *Offerings*: title, type (trial / one-to-one), duration, price, mode, cancellation policy; publish or archive.
5. **Availability** — weekly hours, blocked days/holidays, extra slots, minimum notice, buffer between lessons and maximum lessons per day.
6. **Credentials** — upload PDF/PNG/JPEG certificates (max 5 MB). They are private and only reviewed by staff. Badges are awarded by an admin decision, never automatically.
7. **Submit for review** — an admin approves or rejects with a reason; your profile becomes public only after approval.
8. **Bookings** — *Bookings*: see requests and confirmed lessons, join the classroom in the join window, then record attendance (present/late/absent), add notes and a materials link, and complete the lesson.
9. **Courses** — *Courses*: build sections and lessons (text, video link, resource, link, quiz), reorder, set price, publish.
10. **Earnings** — *Earnings* shows the append-only ledger (gross, platform fee, refunds). **Payouts are not available yet**: no payout provider is set up, so there is no withdraw button.
